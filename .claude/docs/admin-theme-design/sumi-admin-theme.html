Palette

Grays lean very slightly warm, like ink on paper rather than on glass. The accent swatch is ink: near-black in light, near-white in dark.

Install Check

The contrast pairs from the theming spec, measured live. Errors need 4.5:1 (3:1 for muted ink); dots are warnings at 3:1.

Open Questions

  1. Selection without a hue. A selected row is a darker wash than hover, plus a filled ink checkbox. Look at the second row: is that enough?
  2. Links. With an ink accent, a link is the same color as text. Components would need to underline links for this theme to work, which is a component decision, not a token one.
  3. The seal. The red dot in the banner is the sketch's nod to an artist's seal stamp. It is sketch art with its own color; in the theme, red stays reserved for danger.
  4. Mincho for headings. Page titles and panel headings use Shippori Mincho; list titles stay sans. Editorial also uses a serif, so does this feel distinct enough from it?
  5. Name and id. "Sumi" is a working name.
