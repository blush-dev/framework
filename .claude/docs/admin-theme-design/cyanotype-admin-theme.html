Palette

Light grays lean cool, toward the paper's blue cast. Dark grounds are true Prussian, not black, so status fills are tinted to sit on blue.

Install Check

The contrast pairs from the theming spec, measured live. Errors need 4.5:1 (3:1 for muted ink); dots are warnings at 3:1.

Open Questions

  1. Neutral is also blue. This is deep Prussian against Neutral's bright cobalt, and the dark scheme is blue all the way down rather than gray. Does it feel like its own theme next to Neutral?
  2. A white accent in dark. Like Sumi, the dark accent is near-white, so links and selection lean on weight and the blue selection wash. Same components question about underlined links.
  3. Blue grounds in dark. Prussian grounds are the most striking part, and also the most tiring over a long session. How deep should they go?
  4. Name and id. "Cyanotype" is a working name.
