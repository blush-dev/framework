Media Detail sketch · not the prototype File Theme

Two columns and nothing else: the file, how it is used and where it lives on the left; the one thing that saves, and what the file says about itself, on the right. Six files, including one that twenty-four entries point at. The heading reads the file’s Title and falls back to its file name — type in the field and watch the heading and the breadcrumb follow. Save, Discard and Delete are live. Both admin themes, both color schemes.
