A Markdown map of the site: its name and description, then each listed type's pages.

llms-full.txt
View llms-full.txt (3.5 MB)

On, the site serves one file holding every page llms.txt lists, in full, so a tool can read the whole site at once. It runs to several megabytes on a large site.

Nothing is served while Markdown copies are off: without them there is no llms.txt to gather.
