# Autocomplete in your editor

Point `$schema` at the schemas in `resources/schemas/` of the framework
(as in the examples in [Making an admin theme](making-an-admin-theme.md)
and [`tokens.json`](tokens-json.md)), and editors that read JSON Schema
will suggest every token, its kind of value, and its range as you type.

- `admin-theme.json`: `vendor/blush-dev/framework/resources/schemas/admin-theme.v1.schema.json`
- `tokens.json`: `vendor/blush-dev/framework/resources/schemas/admin-tokens.v1.schema.json`
