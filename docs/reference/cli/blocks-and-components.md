# Blocks and components

Listing the blocks content can use and the components a theme can use.

| Command | What it does |
|---|---|
| `block:list` | List the [blocks](../../concepts/blocks/README.md) your content can use: each one's full name, its label, its class (if it has one), its [variants](../../features/blocks/README.md) under your theme, and the file that draws it. Also points out files in `blocks/` that aren't for a registered block. `--theme=` lists for another theme, by name. |
| `component:list` | List the [components](../../features/components/README.md) your theme can use: each one's full name, its class (if it has one), and the file that draws it. Also points out files in `components/` that aren't named for a component. `--theme=` lists another theme's, by name. |
