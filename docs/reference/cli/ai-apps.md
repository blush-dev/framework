# AI apps

Serving the MCP server to an AI agent on the same computer.

| Command | What it does |
|---|---|
| `mcp --account=<username>` | Serve the [MCP server](../../features/mcp/README.md) over standard input and output, as an account, for an AI agent on the same computer. It works whether or not the MCP server is on for the web, needs no token, and refuses a suspended account. |
