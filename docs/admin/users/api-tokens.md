# API tokens and connected apps

An account's screen lists its API tokens and the AI apps connected as
it, and makes and revokes them.

## API tokens

**API Tokens** on an account's screen lists its
[API tokens](../../features/api/README.md): each one's name, who made it
and when, what it **Can** do, when it was last used, and when it
**Expires** (**Expired** for one that has).

**New Token** asks for a
name, how long it lasts (**30 Days**, **90 Days**, **A Year**, or
**Never**), and what it can do: **Read**, **Write drafts**, **Same as
the account**, or **Choose**, which opens the account's capabilities
as a role's screen draws them. The token is shown once, with **Copy
Token**. **Revoke** stops one; **Revoke All** stops every one.

On [Your Account](your-account.md) you make your own (the owner and administrators can, by
default); on another's, whoever can edit accounts sees and revokes
them, and makes them only for a token-only account. The
[dashboard](../dashboard.md) warns when one of yours expires within a
week.

## Connected apps

**Connected Apps** lists the [AI apps](../../features/mcp/README.md) connected
as the account, each with what it may do, when it was approved and
last connected, **Activity**, and **Disconnect**; **Revoke All**
disconnects them too.
