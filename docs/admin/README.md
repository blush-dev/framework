# Using the admin

The admin is where people with an [account](../concepts/accounts/README.md)
run the site from a browser. It has a dashboard (what you were editing,
and the entries waiting on you), a list of each content type's entries,
an editor, the media library, screens for the site's structure,
extensions, people, and settings, Site Health, and a Tools section
(buttons to publish, reindex, and clear caches, background jobs,
activity, redirects, backups, and the site's log).

> **The admin is early.** The editor edits Markdown as text; a live
> preview, a form for a block's options, and a media library come
> later.

To build an admin of your own on the admin's API, see
[Your own admin](../features/admin-api/README.md).
