# Backups

With `site.backups` (owners), **Tools → Backups** lists the site's
backups and makes them, and with `site.backups.restore`, restores them.

See [Backups](../running/backups.md) for what's in a backup, and
[Restoring a backup](../running/restoring-backups.md) and
[Backing up on a schedule](../running/scheduled-backups.md).
