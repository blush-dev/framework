# Addresses and Search settings

**Settings → Addresses and Search** sets how the site's addresses end,
and what it tells search engines.

- Whether addresses end in a slash (`/about/`; the other form
  redirects, so old links keep working).
- Whether the site has a sitemap and `robots.txt`.
- The paths `robots.txt` asks search engines to skip, one a line.

Shown: the media address, and whether search engines are asked not to
index the site (outside production, they are).
