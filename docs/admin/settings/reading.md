# Reading settings

**Settings → Reading** sets the homepage and the site's feeds.

- **Homepage:** the page at `user/content/index.md`, or the latest
  entries of a collection (see [Pinned entries](../pinned-entries.md#the-root-page-and-the-homepage)).
- **Feeds:** the formats (RSS, Atom, JSON Feed; none turns feeds off),
  whether they carry each entry's full content, and how many entries
  each holds (1 to 100).
