# Brand marks

The marks of the sites Blush embeds from, for the Writing screen's
embeds (D-695): Simple Icons 13.21.0 (CC0 1.0, `LICENSE.md`), one SVG
each, named by the embed provider's `name` (`youtube`, `x`). They're
bundled by `js/brands.ts`, not copied.

To add or update one, copy `icons/{slug}.svg` from the same version of
the `simple-icons` package (https://simpleicons.org) here, as it is, and
name it for the provider. A provider without a mark gets the admin's
`globe` icon.
